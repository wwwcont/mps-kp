## 1. Ситуация

- Курсовая «Разработка микропроцессорной системы на базе МК i8051» (МПС ч.2), НИУ МЭИ, ИВТИ, кафедра ВМСС.
  Руководитель — Михалин С.Н. Группа А-12-22.

  Курсовую Иван делает заново, **вариант придёт новый** (номер M пока неизвестен).
  Всё, что считалось для «варианта 14» (А-12, M=14), — это эталон для проверки генератора, а не финальные данные.
- Цель шире одной курсовой: сделать общую базу для группы — генератор (параметры, схема KiCad,
  дальше ПЗ и асм-заготовки) + рыба + общие заметки, куда пишут люди и Claude-сессии.

## 3. Предметная часть — как устроено устройство

AT89S53 (8051) на 12 МГц. Внешняя шина: P0 (адрес/данные, защёлка 573 по ALE), P2 (старший адрес + CS),
P3.6/P3.7 = WR/RD. Четыре устройства на шине, у каждого свой CS на одной из P2.3–P2.7 (активный 0):

- **Индикатор** — регистр 573 + 8 резисторов + FYS-5612AX (общий катод) / BX (общий анод). Статическая индикация.
- **Клавиатура** 12 клавиш — 173 пишет столбцы (Col) с шины, 244 отдаёт строки (Row) на шину;
  RC-фильтры и подтяжки на строках, диоды в столбцах, «И» по строкам → INT (по спаду).
  Сканирование «бегущим нулём» по столбцам. M чётное → 4×3, нечётное → 3×4.
- **Кольцевой буфер** — двухпортовое ОЗУ IDT7005: левый порт — МК (movx), правый — внешнее устройство (X2).
  Механизм (с 19.10.2026, changelog /30, ответ Михалина «DD11, DD12 не требуются; кто управляет буфером?; какие операции слева и
  справа по ТЗ?; нельзя выходы к источнику»): схема методички (прил. А) — CS_buf и адрес МК на оба порта, слева только чтение
  (OE ← RD, R/W = 1, CE = ИЛИ(CS_buf, RD)), справа только запись X2 по WR МК (OE = 1); строб X2 → INT1, обработчик делает movx-запись по «голове».
  M/S = 1 (master), BUSY и INT — свободные выходы; адресных линий — по V, старшие A — на землю. Указатели и флаги — МК.
- **Регистр Y2** — 573, Load = ИЛИ-НЕ(CS_Y2, WR). Стробы Y1/Y2 — прямо с ножек P1.
- Y2 = (M + X1 + X2) mod 256, пока X1 ≠ 0 и в буфере есть данные; иначе Y2 = 0.

Адреса: буфер ≤ 2048 байт → A0–A10 (P0 + P2.0–P2.2); старший байт адреса устройства = F8h со сброшенным
битом его CS (P2.7 → 7800h, P2.6 → 0B800h, P2.5 → 0D800h, P2.4 → 0E800h, P2.3 → 0F000h).

**Чем варианты отличаются по железу** (важно для генератора): только (1) какие P2.x на каких CS,
(2) какой INT у клавиатуры, (3) биты P1 под стробы, (4) клавиатура 4×3/3×4, (5) индикатор катод/анод.
Размер буфера разводку не меняет. Остальное — программная часть.

«Общую часть» схемы никто не выдаёт — её каждый рисует сам; на деле в группе ходит один шаблон
из года в год (схемы Ивана, ММС, АИВ — один шаблон с одними ошибками).

## 4. Найденные проблемы (важно не повторить в новой работе)

В старой схеме/ПЗ1 Ивана:
1. **Сброс**: на RST только 10 кОм на GND, нет конденсатора от +5 В — сброс при включении не гарантирован
   (правильно сделано у ИАВ: кнопка + RC).
2. **Фильтрующие конденсаторы 68 пФ** на схеме и в перечне — по ТЗ 68 **нФ**.
3. **Логика ТТЛ** (7402, 74AS21, 74AS32, 74AS573) — ТЗ просит КМОП (1554/1564/74HC/74AC).
4. Опечатки в ПЗ1: для длительности RD продублирован t_AVLL (должен быть t_RLRH) (R/WL на диаграмме записи теперь верно: МК пишет левым портом).
5. В ПЗ1 не хватает: оценки мощности, описания механизма доступа внешнего устройства к буферу,
   временной диаграммы обмена МК ↔ IDT7005 (п. 2.1 и 2.3 ТЗ).
6. Проверить арбитраж BUSY IDT7005: при записи через INT оба порта обращаются к одному адресу одновременно
   (левый — в режиме чтения). В режиме master запись на проигравшем порту может блокироваться.

В схемах одногруппников:
- ИАВ и Осипова ставят символ **IDT7006PF** и переименовывают в IDT7005 — номера выводов не от 7005.
- У АИВ и ИАВ не проставлены номиналы R/C.

## 5. Генератор — состояние

Всё в этом репо, см. `README.md` и `CLAUDE.md`. Сделано и проверено:
- калькулятор варианта (все группы × M = 1..30 без ошибок; эталон А-12 M=14 совпал с ручным расчётом);
- патчер схемы: 8 меток (4 CS, Y1/Y2, 2 INT) переезжают на нужные выводы; прогон 4 разных вариантов через
  `kicad-cli` — ERC идентичен мастеру; полный лист с ГОСТ-рамкой рендерится;
- рамка: вариант вписывается автоматически; многострочные надписи разбиты на строки (kicad-cli рисовал их внахлёст);
- CI на GitHub Actions (артефакты хранятся 7 дней — иначе кончится квота 500 МБ на бесплатном аккаунте).

Временный мастер `masters/kb4x3-cathode.kicad_sch` — схема Осиповой (А-12, вар. 12) из папки группы.
Минусы: IDT7006PF, нет конденсатора сброса, не везде номиналы, рамка без боковых граф.
Репо поэтому держать **приватным**.

Шрифт `GOST type A` в репо не лежит (лицензия ASCON, freeware — лучше не распространять).
Брали отсюда: `https://raw.githubusercontent.com/koson/PowerSupply/master/Template/GOST%20type%20A.ttf`
→ положить в `fonts/` (CI подхватит) и поставить локально.
